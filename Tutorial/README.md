# CS146S 中文自学教程：从模型输出到可靠软件

这是一套不依赖视频的文字教程。你将通过原理解释、贯穿项目、实验步骤和验收标准，学习如何让 Coding Agent 参与软件开发，同时保留对需求、正确性、安全和发布的控制。

本教程不是官方讲义译本，也不是“输入一句话就自动做完产品”的承诺。它基于仓库的 [课程说明](../README.md)、[Fall 2025 资料](../Resource/Fall2025/) 和 [_assignments](../_assignments/)，对知识重新编排并补充工程解释。幻灯片仅用于溯源，不是完成正文学习的前置条件。

## 你最终应该能做什么

- 解释 LLM、工具调用和 Agent loop 的区别，区分模型建议与运行时实际执行。
- 将模糊需求变成可检验的规格，再通过研究、规划、实现和测试推进任务。
- 设计可组合、有权限边界、能够恢复失败的 MCP 工具。
- 用测试、审查和实验评估 AI 产物，而不是只凭演示成功判断质量。
- 把重复工作编码为自动化流程，并安全地管理并行 Agent。
- 为 AI 功能设计监控、降级、发布和事故响应，理解 Software Factory 的边界。

## 前置能力

课程前置条件现为相当于 CS111/CS161 的基础。你应当能够独立阅读函数、写基本测试、理解 HTTP 请求与数据库操作，比较算法复杂度，并使用 Git 查看差异。不会这些内容时，先完成第 00 章的诊断练习；本教程不能替代编程入门和基础软件工程课程。

工具选择不是学习目标。章内基础路线只需阅读假材料、作答与核对答案，不要求安装 Coding Agent、联网或运行应用。选择实际实验时，再准备支持相应读写与测试的工具；原作业中的 Cursor、Claude Code、Warp、Graphite 和 Bolt 有各自的平台要求。替代方案会明确标记为自学改编，不承诺满足原作业或免费额度资格。

基础阅读、离线测试与本地改编不强制购买会员。云端调用按官方或组织授权渠道确认访问与预算；安装、登录、订阅和 API 计费分别验收，不通过第三方提交登录会话来解锁学习。

## 课程与自学评分

根 README 当前课程评分为期末项目 50%、每周作业 15%、开源贡献 30%、课堂参与 5%。这是课程说明，不等同于第 10 章的 100 分自学项目 rubric。开源贡献训练要求复现、最小修复、回归证据和维护者反馈；不擅自改动自学评分总分，也不以 PR 数量代替有效贡献。

## 建议的十周安排

每周约 10 至 12 小时是课程 README 的建议投入，而不是完成保证。推荐分配为：阅读和自测 2 小时、动手 5 至 6 小时、评估与修复 2 小时、复盘 1 至 2 小时。第 00 章在第一周开始前完成，第 01 至 10 章大致各占一周；MCP 与综合项目可能需要额外时间。

每章基础先从具体任务与失败理解机制，独立作答后对照章内答案，记录理由与未知。时间按各章估计安排，可分次完成。选择实际实验后，再按“预测、运行、定位、最小修改、独立验收”推进；课程建议投入不等于纸面基础的最低时长。遇到阻塞可以缩小任务，但不能把未运行写成通过。

## 贯穿项目：行动项提取与开发者控制中心

第 2 周原作业提供 FastAPI + SQLite 行动项提取器：输入会议笔记，得到任务列表。第 4 至 7 周提供开发者控制中心应用。教程用这条业务主线连接知识，但这些周目录是不同练习快照，不是可直接串接的数据库迁移版本。

你的学习项目逐步增加以下能力：笔记输入和规则基线、LLM 提取、结构化契约、MCP 搜索与受控写入、测试和审查自动化、权限防护、观测与降级。数据库、网络或真实账号写入只在隔离的练习环境中进行。
