# CS146S 中文自学教程：学会用 AI 开发可靠软件

这套文字教程帮助你学会与 AI 编程助手（Coding Agent）合作：把需求讲清楚，让它协助写代码，再用测试和审查确认结果。你不需要观看视频，基础学习也不需要安装工具或调用模型。

教程围绕一个项目展开：先从会议笔记中提取待办任务，再逐步加入搜索、保存、自动化检查和上线维护。重点不是记住工具名称，而是知道哪些工作可以交给 AI，哪些结果必须自己核实。

## 你最终应该能做什么

- 把模糊需求写成明确要求，并说明怎样判断任务完成。
- 理解 AI 如何读取文件、调用工具和修改代码，设置必要的权限限制。
- 用测试和代码审查发现问题，而不是只看演示是否成功。
- 将重复工作自动化，并在出错时停止、恢复或回退。

## 前置能力

你需要有基本编程经验：能读懂函数、写简单测试、理解 HTTP 请求和数据库操作，并用 Git 查看代码变化。不确定是否准备好，可以先做第 00 章的诊断练习。

基础路线只需阅读案例、完成练习并核对章内答案。实际运行实验时，再准备对应工具和隔离的练习环境，确认权限与费用。基础阅读不要求购买会员；不要向第三方提供登录凭据。

## 建议的十周安排

先完成第 00 章，再按每周一章学习第 01–10 章。时间有限时，只读本章的主案例和基础练习，留下一份能核对的产物（例如第 01 章的预期答案、第 02 章的调用时间线），进阶部分按需展开。原课的每周 10–12 小时可用作含实操的规划参考，不是纸面路线的必需投入。

学习时先自己作答，再看答案。动手时先写预期结果，运行后检查差异，修复后重新测试。任务太大就缩小范围，不要把“尚未运行”记成“已经通过”。

## 贯穿项目

项目从“输入会议笔记，提取待办任务”开始。不必等到最后一章才动手：第 03 章写完规格就可以走[离线项目检查点](chapters/03-context-spec.md#可运行检查点从规格到行动项项目)，第 07 章给同一实现补独立回归和审查记录，第 09 章再检查持久化、降级与恢复。按[第 10 章里程碑](chapters/10-capstone.md#2-五个交付里程碑)记录进度；起步实验不是成品，不要求另开一个项目来练每个工具。

原作业各周目录是独立的练习版本，不能直接当作同一个项目的连续升级。建议在独立练习仓库中实现，保留本仓库作为参考，不清空已有作业或翻译文件。

## 完成判据

| 学习层次 | 怎样判断完成 |
| --- | --- |
| 理解方法 | 完成章内练习，能解释自己的选择和可能的失败原因 |
| 换个场景也会用 | 独立回答章内“迁移检查”，再对照答案，找出遗漏 |
| 实际做成 | 在隔离环境中运行项目，提供测试结果，并说明剩余风险和恢复办法 |

记录结果时，要分清练习中的假设、实际观察、自己的推测和尚未验证的部分。综合项目要求与自学评分见 [第 10 章](chapters/10-capstone.md)。
