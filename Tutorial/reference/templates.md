# 实验与规格模板

[返回目录](../README.md)

模板是记录结构，不是已经完成的结果。未知字段写“待确认”，没有运行写“未运行”，不得预填成功。

## 1. 一页规格

| 字段 | 填写内容 |
| --- | --- |
| 目标与用户 | 谁遇到什么问题，本轮改善什么 |
| 当前行为与来源 | 代码、测试或文档的位置与版本 |
| 目标契约 | 输入、输出、边界和错误 |
| 非目标 | 明确不做的功能和重构 |
| 数据与权限 | 资源归属、读写范围、敏感数据 |
| 方案与权衡 | 最小调整、替代方案、选择理由 |
| 文件范围 | 预计修改与生成文件 |
| 验收 | 正常、失败、对抗与隐藏样例 |
| 发布与回滚 | 门禁、备份、兼容性与恢复 |
| 未确认项 | 需要用户或团队决定的问题 |

```text

角色与整体超时、重试、预算、停止条件：
原始发现、按根因去重后的发现与位置：
确认缺陷 / 误报 / 待验证及各自证据：
```

没有已知缺陷全集时，不填写真实召回率；模型一致意见不代替人工批准。超时和认证失败留在记录中，不删除以改善成功率。
