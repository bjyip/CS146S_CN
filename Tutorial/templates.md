# 实验与规格模板

[返回目录](README.md)

模板是记录结构，不是已经完成的结果。未知字段写“待确认”，没有运行写“未运行”，不得预填成功。

## 1. 一页规格

| 字段 | 填写内容 |
| --- | --- |
| 目标与用户 | 谁遇到什么问题，本轮改善什么 |
| 当前行为与来源 | 代码、测试或文档的位置与版本 |
| 目标契约 | 输入、输出、边界和错误 |
| 非目标 | 明确不做的功能和重构 |
| 数据与权限 | 资源归属、读写范围、敏感数据 |
| 方案与权衡 | 最小调整、替代方案、选择理由 |
| 文件范围 | 预计修改与生成文件 |
| 验收 | 正常、失败、对抗与隐藏样例 |
| 发布与回滚 | 门禁、备份、兼容性与恢复 |
| 未确认项 | 需要用户或团队决定的问题 |

## 4. 工具契约

| 字段 | 填写内容 |
| --- | --- |
| 工具名称与目的 | 面向用户目标，不只是 API 名称 |
| 参数 schema | 类型、枚举、范围、必填与额外字段 |
| ID 来源 | 来自哪个前置工具的哪个字段 |
| 输出 | 必需字段、分页、截断与版本 |
| 错误 | 代码、可否重试、后续行动 |
| 副作用 | 修改什么，是否可撤销 |
| 权限 | 身份、scopes、路径和网络 |
| 写入刹车 | dry-run 或预览/批准/提交 |
| 幂等与超时 | 如何避免重复写入 |
| 验证 | 函数、协议、供应商和客户端测试 |
