## 2. 从文书到共享意图

共同可见的引言回顾规格越来越短、甚至以餐巾纸草稿参加评审的现象，强调规格不是交付前随手写完的文书，而与产品交付、质量共同构成执行基础。

中文版后续将作者论点概括为：AI 加快实现后，明确构建什么、理解客户和对齐需求可能成为瓶颈。这里讨论的是产品组织的趋势，不是所有团队的实测结论；需求、实现、验证和运维的瓶颈仍取决于具体系统。

规范的价值不是篇幅。目标、用户、可观察行为、边界和取舍应能让不同读者形成相近理解。只写“智能、高效、好用”不能承担这一角色。

## 3. “规格是新源代码”的类比与边界

中文版“规格说明书——新的源代码”转述 Sean Grove 的演讲：若保留生成代码却丢弃提示和规格，就像只保留二进制、丢弃源代码；代码不完整表达意图，规格可协调人和模型，并支持不同产物。

本轮没有观看该演讲，也没有读英文对应全文，因此这段归属为中文页的转述，不当作直接核验演讲原话。类比提示应版本化意图和决策，但不能据此把实现当可随意删除的副产品。

传统编译在受控条件下有明确语义，LLM 从规格生成代码还依赖模型、上下文、工具、依赖和人工修改；相同规格不保证产生相同、正确或等价实现。源代码、测试、数据迁移和部署配置仍是必须维护的工程证据。规格与实现不同步时需要复核需求，不是自动以某个文件覆盖另一方。

| 工件 | 保存什么 | 不能替代什么 |
| --- | --- | --- |
| 规格 | 用户意图、行为、非目标与验收 | 实际运行结果和未知需求澄清 |
| 设计决定 | 方案选择、排除理由与约束 | 当前依赖和调用链核验 |
| 代码与配置 | 实际实现、人工修复、运行条件 | 用户价值与所有隐含意图 |
| 测试与结果 | 独立预期、命令、版本和失败 | 未覆盖行为或真实模型质量 |

## 4. 原型不是取消规格

中文版“原型不是应该取代规格说明了吗”对照先写规格再开发 MVP，与先做快速原型、取得反馈、形成更清晰规格再实施。原型在这里是探索和沟通工具，规格可以成为探索的输出，而不是所有细节事先固定的输入。

“不写代码做原型”是对参与者工作方式的描述，原型工具仍可能生成代码。客户喜欢界面不证明授权、持久化、无障碍、并发和错误处理已验收；从原型抽取稳定行为，再由独立检查验证实现，避免把演示成功当完整需求。

## 5. 中文版所述 decimals 案例

案例描述 Danny Martinez 的人才推荐平台：联合创始人希望在创作者主页加入跳转职位申请页的按钮。中文页列出 Slack 消息转 Linear 工单、补明确要求、用 Copilot/Claude 阅读工单与仓库、创建分支实施、测试、PR 和工程师审查的流程。

这是中文译述提供的案例文字，没有原始工单、差异、测试或上线证据，不能声称本轮复现。中文页把 PR 的目标合并过程与工程师审批放在连续步骤中，教程必须区分创建 PR、等待审查和批准后合并；创建 PR 本身不等于合并到主分支。

该页明确三项条件：需求具体，简单任务选择性自助，懂业务的工程师把关。非技术参与者能表达意图不等于适合独立处理认证、迁移或高风险发布；监督应按风险与证据决定，而不是按工具品牌决定。

## 6. 受控练习：从反馈提取契约

以下是行动项提取器的教程扩展，不是 decimals 案例复原。预算 40 分钟、零网络、零费用、零模型调用，不安装工具或创建远程 PR。本轮未运行。

假反馈：“最新笔记应先看到，网络慢时不要重复创建，模型失败时让我知道。”原型只有正常列表截图，没有数据库与异常证据。

1. 从反馈提取三条可观察要求，补排序并列规则、重复请求约定及降级展示；不明确的业务选择标待确认。
2. 用[一页规格模板](../../../reference/templates.md)写目标、非目标、权限与验收，保留原反馈定位。
3. 写三条独立验收及一个隐藏边界样例，将排序、重复写入、模型降级分别映射；截图不能填测试通过。
4. 写一次假变更交接，包含规格版本、实现范围、决定理由和未运行检查。即使生成代码，也不得删除规格、人工修复或测试记录。

验收：反馈与契约可追溯，未知未被猜测填满，规格和实现证据分开，PR 创建与合并区分，原型与产品验收区分。纸面规格不能验证生成可靠性或产品收益。

## 7. 自测与答案

**问：规格更重要是否意味着可以删除代码？** 不意味着。生成不等于确定性编译，代码、测试和运行配置仍需版本化维护。

**问：原型反馈能替代规格吗？** 不能。反馈帮助形成规格，可见演示不足以表达失败、权限和发布边界。

**问：这份笔记是否完成英文全文与中文译文对照？** 没有。英文仅公开预览，中文是声明删减的公开译述，后半内容忠实度和遗漏仍待核验。

**问：创建 PR 是否等于上线？** 不等于。审查、批准、合并、部署及运行验收是不同阶段，按项目实际流程记录。
