## 1. 提示的四类要素

原页区分指令、上下文、输入数据和输出指示。情感分类例子用分类要求说明任务，用一句评价作输入，用“情绪：”提示答案位置；没有额外背景也可以构成提示。四项是分析框架，不是所有请求都必须填满的表单。

用于行动项提取时，指令定义只提取明确可执行事项，上下文说明业务中“任务”的含义，输入是会议笔记，输出指示规定对象与字段。教程扩展要求把会议文字当数据，并在执行层限制工具：分隔符有助阅读，不是授权机制；“输出 JSON”也不是严格 schema 校验。

同一内容可能承担不同职责，例如示例既提供上下文，也暗示输出格式。核对重点是示例与规则有没有冲突，是否泄漏留出答案，失败时程序怎样处理，不是机械计算四项数量。

## 2. 采样设置不能当事实开关

原“模型设置”页将较低 temperature 与较少随机性联系起来，并建议一般只改变 temperature 或 top_p 之一。这里需要保留三项限制。

- 低随机性不等于正确事实。某个错误候选本来概率最高时，更尖锐的分布可能更稳定地返回错误。
- 中文页称调低 temperature 会增加“其他可能的 token 的权重”，措辞与通常的采样缩放解释不符。对于固定 logits、正温度 T，常见机制为 `p_i(T) = exp(z_i/T) / Σ exp(z_j/T)`：降低 T 放大相对差异，更偏向高 logit 候选。此公式是教程补充，不声称已完成英文翻译校准，也不推断所有供应商实现或 T=0 行为。
- top_p 通常依据概率排序保留达到指定累计质量的候选集合，再从该集合采样；它不是“有 top_p 比例的事实正确”。页面将两种设置一起称为核采样，本笔记区分温度缩放与累计概率截断，不将术语混用。

简介页沿用 gpt-3.5-turbo、temperature=1、top_p=1 的历史示例说明。不能据此推定当前模型默认值、参数支持、确定性或跨供应商兼容；实际操作应另读当前 API 文档。零调用练习只验证理解，不记录参数效果实测。

## 3. 长度、停止串与惩罚的职责

长度上限限制生成预算，不保证输出在截断时仍是完整 JSON，也不代表整个 Agent 任务的时间或费用上限。停止串触发文本停止，不是业务计数器。原页用“11”表示列表最多十项，存在局限：正文出现该字符也可能提前停止，模型未输出该字符则不能靠它约束项目数。程序应校验列表长度与完整结构。

Frequency penalty 按已出现次数影响重复倾向，presence penalty 更关注是否出现。具体计数范围、公式与参数支持依提供商而定；不能拿本页概述填现行 API 契约。行动项里重复出现同一服务名可能是正常内容，减少重复 token 不等于正确去重业务任务。

## 4. 通用技巧中的反例也要核对

原页建议从简单提示开始、小步迭代、拆解任务、明确目标与格式，并避免无关细节。这里的“越详细越好”应与同页的相关性与长度限制一起读：增加必要约束有价值，堆入重复或矛盾描述可能增加错误。

两个原文字例子值得独立检查，不能把展示输出直接当合格答案。

| 原例 | 可见问题 | 教程解读 |
| --- | --- | --- |
| 提取地名 | 格式占位却写“公司名称列表”，输出还包含研究中心 | 指令、字段语义和实体类别需要先统一；本批未读 Nature 转引正文，不裁定其完整实体标签 |
| 不询问兴趣的电影推荐 | 改写后输出称不知道兴趣，接着给热门列表；没有验证真实片单或个性化效果 | 明确允许的替代回答比单纯禁止更可操作，但该输出不是满足所有分支的证明 |

要求“该做什么”可以改善表达，不意味着必须删除安全禁令。教程扩展应同时写允许行为、禁止边界和缺信息时的处理，例如“不补负责人；缺失则留空并说明依据不足”，再由程序与权限配置验收。

## 5. 零调用练习与验收

预算 35 分钟，只做纸面推演，零网络、模型、安装和文件执行；不修改原作业。以下概率与输入均是教程假数据，不是作者测量。

1. 为“明天请检查日志；发布已经完成；负责人尚未确定”写四要素提示。任务只含检查日志，不补姓名；再留一条未参与设计的否定输入作为验收。
2. 假设两个候选概率为 A=0.6、B=0.4，独立业务证据只支持 B。说明低随机性为什么仍可能偏向错误 A，不填写真实模型准确率。
3. 对假列表中一项文字含“11”与输出被截成半个 JSON 两个事件，分别写格式失败、业务项数与恢复契约；最多允许一次修正，仍失败则停止。
4. 为实体提取例统一目标类别与占位字段；对电影推荐写缺信息、无候选和正常候选三个分支，不查询真实片单。

验收提交四要素提示、独立留出输入与预期、两个截断失败契约、三路缺信息处理。结果表使用“纸面预期/未运行”，不以更长提示、低 temperature 或完整 JSON 代替业务成功。

## 自测与答案

**问：temperature 越低越真实吗？** 不成立。它改变采样分布，不补充事实；高概率错误仍可能更稳定。

**问：stop="11" 能保证十项列表吗？** 不能。它匹配文本而非计数，可能提前停止或未触发；项数与结构需要独立校验。

**问：四要素齐全就能防注入吗？** 不能。表达清晰与执行权限不同，外部输入不能升级为系统授权。

**问：读完本笔记是否补齐 Google 概览或视频？** 没有。只补学习目标，不证明不同作者、不同材料的指定正文已读。
