## 1. 十类提供观察方向，不提供安全证明

Top Ten 是安全意识文档，帮助开发者和组织理解常见高风险领域。“如何作为标准”页面强调它是最低起点，不是完整可验证标准，并建议进一步使用 ASVS 等资料。本轮未读取完整 ASVS，因此不编造其版本或条目编号。

2021 选类包含八项数据驱动类别与两项行业调查类别，考虑自动扫描较难充分观察的新兴风险。统计按存在至少一个相关 CWE 的应用发生率，而不是简单累加报告次数，避免工具容易大量发现的问题吞没其他风险。

中文首页和介绍对约 94% 的描述容易让读者混淆覆盖率与发生率；类别表将平均发生率和覆盖率分列。不能转述为“94% 应用都有某漏洞”，也不能把某类测试覆盖比例当风险概率。

## 2. 2021 分类与原文案例

| 2021 类别 | 中文机制解读 | 原文案例的学习点 |
| --- | --- | --- |
| A01 Broken Access Control | 权限控制失效 | 即使查询参数化，改变对象 ID 仍可能读到他人数据 |
| A02 Cryptographic Failures | 加密失效 | 数据库读取时自动解密，不能靠静态加密抵挡注入后取数 |
| A03 Injection | 注入，2021 包含 XSS | 拼接 SQL/HQL 让输入改变解释器的指令结构 |
| A04 Insecure Design | 不安全设计 | 恢复问题、预订与黄牛等业务机制风险不能只靠补语法解决 |
| A05 Security Misconfiguration | 安全配置错误 | 默认样例、目录列表、详细错误、云权限可能暴露能力 |
| A06 Vulnerable and Outdated Components | 脆弱与过期组件 | Struts 与难升级 IoT 说明依赖盘点、公告与升级链的重要性 |
| A07 Identification and Authentication Failures | 身份识别与认证失效 | 公共电脑的会话未正确失效会让下一使用者继承身份 |
| A08 Software and Data Integrity Failures | 软件与数据完整性失效 | 未签名更新、不安全反序列化与供应链改变可信执行内容 |
| A09 Security Logging and Monitoring Failures | 日志与监控失效 | 长期未发现泄漏说明告警、响应和调查链也属于安全能力 |
| A10 Server-Side Request Forgery | 服务端请求伪造，SSRF | 服务替用户取 URL 时可能触达内网或云 metadata |

表中案例均为原类别页的中文机制转述，没有复刻攻击参数。分类不是互斥的漏洞桶：同一事件可能同时涉及注入、越权、配置与监控，但每项修复仍需要明确根因与责任边界。

## 3. 三个容易误用的结论

**参数化查询不等于完整授权。** 它保护查询结构，但若对象查询只依据客户端 ID 而不核对当前主体，就仍可能越权。这也连接本周 Unit42 的 BOLA 场景。

**加密不替代数据访问控制。** 数据在合法读取路径中会解密；攻击者若借同一路径取得数据，存储加密不能自动阻止泄漏。威胁模型必须说明防护针对离线介质还是在线服务访问。

**不安全设计不能全靠扫描补齐。** 业务允许的行为可能被滥用，例如预订资源的规则缺乏限制。需要在规格阶段明确攻击者能力、业务不变量和拒绝条件，而不只是修复异常字符。

以上是基于类别页的教程归纳，不是新 OWASP 排名或特定扫描工具覆盖声明。

## 4. 零执行练习：把风险类别变成可审查条件

预算 40 分钟；零网络、零模型、零扫描、零真实账号、零代码执行。教程假设行动项系统包含任务详情、附件 URL、导入文件和会话。

1. 用 10 分钟选 A01、A08、A10 三类，分别写当前主体能读哪个任务、哪些导入内容可信、附件读取可去哪些目的地。
2. 用 15 分钟为每类写一个正常案例和一个拒绝案例，不使用真实身份、地址或攻击 payload。
3. 用 10 分钟列出计划取得的证据：服务端授权测试、导入完整性记录、网络目的地检查；未执行一律写“待运行”。
4. 用 5 分钟标出清单未覆盖的业务风险，避免把 Top Ten 三项通过写成系统安全验收通过。

验收：至少六个假设案例都有预期、控制点和证据；认证与对象授权分开；版本明写 2021；覆盖率与发生率分开；未把风险类别当完整可测标准。

## 5. 自测与答案

**2025 主页能证明本文采用 2025 排名吗？** 不能。本文明确锁定并读取 2021 页面；主页只用于识别版本变化。

**Top Ten 没列出的风险可以忽略吗？** 不可以。它是意识与入门清单，系统仍需完整威胁模型和适用的可验证要求。

**大量告警次数说明某风险最普遍吗？** 不一定。重复报告、工具能力、覆盖及应用分母都会影响统计，必须核对指标定义。

**A01 与 A07 是同一问题吗？** 不是。认证回答是谁，授权回答这个主体能对哪个资源做什么；认证正确仍可越权。
