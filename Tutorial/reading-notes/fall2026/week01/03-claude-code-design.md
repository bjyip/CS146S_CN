## 1. 简单循环不等于简单系统

定位：第 3.1、3.2、3.4 节和第 4.1 节。

作者把系统分成用户、交互入口、Agent loop、权限系统、工具、状态与持久化、执行环境七部分。模型决定提出什么动作，harness 负责解析请求、判断权限、执行工具、收集结果。模型不是直接获得文件系统和网络的任意入口。

第 4.1 节的流程可简化为：组装上下文 → 调用模型 → 收到工具请求 → 权限检查 → 执行并回填结果 → 下一轮。没有工具请求是主要结束条件，但第 4.5 节还列出轮数上限、上下文溢出、Hook 干预和显式中止。**循环停止只说明控制流结束，不说明用户目标已经正确实现。**

第 3.4 节特别澄清：`QueryEngine` 是非交互入口使用的会话包装类，真正共享的是 `query()` / `queryLoop()`，不能仅凭类名画成所有入口的执行引擎。

原文贯穿案例是“修复 `auth.test.ts` 中失败的测试”。教程补充案例是行动项提取器：模型提出读取会议记录、修改解析器、运行测试；执行层逐个验证权限，最终仍需比较预期行动项与实际输出。模型说“已修复”不是测试证据。

## 2. 并行与上下文都是资源调度问题

定位：第 3.6、第 4.2–4.4 节。

作者描述工具执行器区分并发安全工具与独占工具：读操作可并行，修改状态的操作需要协调。这里是所分析实现的策略，不是“所有 shell 永远不能并行”的普遍定律。两个测试若都修改同一缓存，即使命令名字不同，也可能互相干扰。

第 4.3 节的五层上下文处理分别针对不同压力：限制过大工具结果、裁剪旧历史、细粒度压缩、生成历史投影视图、最后再调用模型作语义摘要。部分路径有 feature flag，不表示所有用户构建都启用。尤其 context collapse 是模型读取时的投影，不等于把磁盘会话历史删除。

教程补充例子：一份 10 MB 测试日志先保留失败摘要与完整日志引用，通常比把整份日志塞入模型再概括更省上下文；摘要必须保留失败测试名、输入、错误位置和未验证事项，否则后续会把“尚未测”误当“通过”。

## 3. 授权、隔离与恢复不能混为一谈

定位：第 5.1、5.2、5.4 节，第 6.1 节，第 9.1、9.2 节。

作者描述 deny 优先于 ask 和 allow；广泛禁止 shell 的规则不会被更窄的允许测试规则覆盖。权限回答“是否准许调用”，sandbox 回答“即使调用获准，运行时能接触哪些文件和网络”。批准命令不等于命令脱离隔离，隔离也不证明行为已获用户授权。

第 6.1 节区分四种扩展：MCP 提供外部工具接入；Plugin 打包与分发多类组件；Skill 注入领域工作流指令；Hook 在生命周期插入控制或上下文。这是本文分析的分工，不宜直接推导其他客户端的加载契约。

第 9 节区分实时上下文、持久会话记录和文件历史检查点。作者说新进程恢复会话不从 transcript 恢复会话级权限，但同一运行进程内恢复或分叉保留已存在的授权。不能缩写成“任何 resume 都清空权限”。文件检查点也不是外部系统的事务回滚，例如已经发出的邮件不能靠回退本地文件撤回。

## 4. 30 分钟离线练习

这是教程扩展，用纸面表格或本地文本即可完成。预算 30 分钟、0 模型调用、0 网络请求；不用真实账号、真实会话或源码运行。

给定假 trace：`Read notes.txt` 返回“李明周五提交草稿”；`Edit parser` 产生补丁；`Bash test` 返回 1 个失败；模型输出“全部完成”；新进程从这份记录恢复。另给规则“deny 所有 shell，allow test”。

1. 0–8 分钟：逐事件标记模型请求、harness 判定、工具结果、持久记录，指出测试请求在该规则下应被拒绝，假 trace 的执行结果与规则冲突。
2. 8–16 分钟：重写一致的 trace，拒绝后改为只读分析，记录未运行测试，不伪造成功。
3. 16–23 分钟：压缩记录成不超过 120 字的摘要，保留用户目标、规则冲突、已改文件、失败或未测状态、完整记录引用。
4. 23–30 分钟：画两列表格，列出恢复后的会话事实与必须重新评估的授权；注明本地回滚不能撤销外部动作。

验收：交付原 trace 的冲突定位、修正版 trace、摘要、恢复表；每个“完成”声明有对应证据，摘要不丢失失败与未测状态。**本次只编写练习，未执行实验。**

## 局限与自测

第 12.5 节指出上下文缓存可能暂时不反映动态变化；附录强调静态源码不能证明生产启用的 flag、设计者意图、运行频率或当前产品行为。本文的安全分层解释不是安全保证，也不复述未核验漏洞的复现步骤。

1. 为什么模型说完成不能作为验收？答案：它是输出声明，必须由测试、实际产物或规格检查独立确认。
2. 压缩是否等于删除历史？答案：不一定；读时投影、模型摘要、磁盘记录是不同层次。
3. sandbox 内运行是否等于获得授权？答案：否，运行隔离与动作授权是两条轴。
4. 恢复会话能否自动恢复全部权限？答案：不能这样概括；本文区分新进程与同一进程，具体产品还需核对当前官方契约。
